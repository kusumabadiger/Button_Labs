# Button Labs – Interactive Button Showcase

An interactive and responsive web project that demonstrates different types of buttons, their purposes, states, and real-world applications.

Button Labs provides a hands-on experience for understanding how buttons work in modern web interfaces through interactive demonstrations and practical examples.

## 🚀 Project Overview

Buttons are essential elements of user interfaces. They allow users to perform actions, navigate between pages, submit forms, confirm decisions, and interact with applications.

**Button Labs** is designed to showcase different button styles and functionalities in one place. Users can explore button types, understand their purpose, test their behavior, and experiment with button properties through an interactive playground.

## ✨ Features

- **Interactive Button Gallery:** Explore different button types with live demonstrations.
- **Button Explanations:** Understand the purpose and common usage of each button.
- **Button States:** Demonstrates default, hover, active, focus, disabled, and loading states.
- **Interactive Playground:** Experiment with button sizes and shapes.
- **Real-World Workflows:** Explore practical examples such as sign-up forms, task completion, and delete confirmation.
- **Toast Notifications:** Displays feedback messages when users perform actions.
- **Confirmation Dialog:** Demonstrates confirmation before performing important actions.
- **Toggle Interaction:** Enable or disable notification settings.
- **Responsive Design:** Works across desktop, tablet, and mobile devices.
- **Modern Theme:** Uses a dark navy, pearl white, and electric coral color palette.

## 🔘 Button Types Demonstrated

| Button Type | Purpose |
|---|---|
| Primary Button | Performs the main action on a page. |
| Secondary Button | Provides an alternative action. |
| Danger Button | Represents destructive actions such as deleting data. |
| Success Button | Indicates successful actions or completion. |
| Warning Button | Highlights actions that require attention. |
| Outline Button | Provides a secondary visual action with an outlined style. |
| Loading Button | Indicates that an operation is in progress. |
| Disabled Button | Prevents interaction when an action is unavailable. |
| Icon Button | Uses an icon to represent an action. |
| Toggle Button | Switches between two states, such as enabled and disabled. |

## 🛠️ Technologies Used

- **HTML5** – Structures the webpage and its content.
- **CSS3** – Handles styling, layouts, animations, and responsive design.
- **JavaScript** – Implements button interactions, notifications, dialogs, and dynamic behavior.

## 💻 Getting Started

Follow these steps to run the project locally.

### 1. Clone the Repository

```bash
git clone https://github.com/kusumabadiger/Button_Labs.git
```

### 2. Navigate to the Project Folder

```bash
cd Button_Labs
```

### 3. Open the Project

Open the folder in Visual Studio Code.

### 4. Run the Application

Open `buttonlab.html` in your browser.

Alternatively, install the **Live Server** extension in VS Code, right-click `buttonlab.html`, and select **Open with Live Server**.
